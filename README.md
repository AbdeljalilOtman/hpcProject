# README

## Overview

This project includes a Python Dash application for managing and monitoring cluster resources, scripts for SSH connection and SLURM job management, and a Bash script for real-time resource monitoring. This guide provides step-by-step instructions to set up and run the project.

---

## Prerequisites

1. **Python Environment**:

   - Python version 3.8 or higher.
   - `virtualenv` or similar tool for managing dependencies.

2. **SLURM Workload Manager**:

   - Installed and configured on the cluster.

3. **Dependencies**:

   - Listed in `requirements.txt`. Install them using pip.

4. **Cluster Credentials**:

   - Access to a cluster with SSH capabilities.

---

## Setting Up

### Step 1: Create a Virtual Environment

```bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Running the Components

### **1. Running the SLURM Script**

#### Step 1: Verify SLURM Availability

Ensure that SLURM commands like `sinfo` are functional:

```bash
sinfo
```

#### Step 2: Submit the SLURM Script

```bash
sbatch script.slurm
```

#### Step 3: Monitor Job Status

```bash
squeue
```

---

### **2. Running the Resource Monitoring Script**

#### Step 1: Make the Script Executable

```bash
chmod +x simlab.properties
```

#### Step 2: Run the Script

```bash
./simlab.properties
```

- Modify environment variables as needed before running the script:
  ```bash
  export PARTITION=gpu
  export MIN_CPUS=4
  export MIN_GPUS=1
  export REFRESH_INTERVAL=5
  ```

---

### **3. Running the Python Scripts**

#### Running `connector.py`

1. This script manages SSH connections.
2. Test it independently by specifying a cluster host, username, and password within the script.
3. Run the script:
   ```bash
   python connector.py
   ```

#### Running `app.py`

1. Start the Dash application:
   ```bash
   python app.py
   ```
2. Open the app in a browser:
   ```
   http://127.0.0.1:8050
   ```
3. Use the provided interface to log in, select a partition, and monitor resources.

---

## Troubleshooting

1. **Missing Dependencies**:

   - Ensure all dependencies are installed using:
     ```bash
     pip install -r requirements.txt
     ```

2. **SSH Connection Issues**:

   - Verify cluster credentials and host availability.
   - Check network settings if the connection fails.

3. **SLURM Errors**:

   - Check the logs generated by SLURM jobs.
   - Use:
     ```bash
     sacct
     ```

4. **Application Errors**:

   - Run Python scripts with debug mode to identify issues:
     ```bash
     python -m debugpy app.py
     ```

---

## Notes

- Ensure your cluster supports SLURM and SSH connections.
- Configure all scripts as required to match your environment.
